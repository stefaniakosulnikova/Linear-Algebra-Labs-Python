# Linear Algebra Labs — SVD и его приложения

Лабораторная работа по линейной алгебре (НИУ ВШЭ): сингулярное разложение матриц и его практическое применение в анализе данных.

## Содержание

1. **Сжатие данных с помощью SVD** — построение низкоранговых приближений и оценка потери информации в зависимости от ранга
2. **Геометрия SVD** — визуализация многомерных данных в пространстве главных сингулярных векторов
3. **Когда SVD не работает** — примеры данных, на которых метод даёт плохой результат, и почему

**Стек:** Python, NumPy, Matplotlib
